# 说明

使用本项目前，你除了需要了解[Cool Admin](https://node.cool-admin.com/)相关知识，
还需要了解一些Ai的基础知识，如：

- 大模型；
- 大模型提示词；
- 向量模型；
- 向量数据库；
- 向量检索；
- 文档重排；
- 文档分块；
- 知识图谱；

可以自己搜索了解相关知识，或者让Ai协助你了解

推荐一个我们都在用的集合了各种Ai模型的问答网站[AskManyAi](https://askmany.cn/login?i=5dbf85cc)

# 核心

无论工具有多强大，要想效果好，你都得好好整理你的文档和知识。不要指望随便一堆文档一扔，它就能有很好的效果。

知识问答系统，知识整理本身就是很重要的一个环节。

模型的能力、提示词等每个小细节都是细心调整优化，这样就能有好的效果。

注意：本项目使用 pnpm 来管理依赖，而且需要升级到 pnpm 最新版本，https://pnpm.io/

```shell
npm i -g pnpm
```

# 依赖环境

- 数据库：pg
- 数据库向量化插件：pgvector
- node 版本：>=22.0.0

docker 安装

```bash
docker pull pgvector/pgvector:pg17

docker run --name pgvector-container -e POSTGRES_PASSWORD=你的密码 -d -p 5432:5432 pgvector/pgvector:pg17
```

安装失败一般是网络问题，多试几次，或者用魔法

安装完成后创建一个数据库名为`flow`，然后修改数据库配置`src/config/config.local.ts`

确保配置正确，项目启动会自动导入数据

## 如何使用其他数据库(不推荐)

Cool Admin 支持 Mysql、PostgreSQL、Sqlite。由于 Mysql 的没落，我们推荐您使用 PostgreSQL，更强大，对向量存储有很好的支持。

但是如果你想用其他数据库，可以根据[数据库配置文档](https://node.cool-admin.com/src/guide/core/db.html)修改。

另外需要单独安装向量数据库，支持`faiss`和`chroma`两种，修改完到`src/modules/know/config.ts`

### chroma 方式

```ts
 // 需要单独安装，推荐docker方式
 store: 'chroma' as StoreTypes,
```

docker 安装 chroma

1、创建 docker-compose.yml 文件

```yml
version: '3.9'

networks:
  net:
    driver: bridge
services:
  server:
    image: ghcr.io/chroma-core/chroma:latest
    environment:
      - IS_PERSISTENT=TRUE
    volumes:
      # Default configuration for persist_directory in chromadb/config.py
      # Currently it's located in "/chroma/chroma/"
      - chroma-data:/chroma/chroma/
    ports:
      - 8000:8000
    networks:
      - net

volumes:
  chroma-data:
    driver: local
```

执行命令

```shell
docker-compose up -d --build
```

### 本地方式

如果你不想安装向量数据库，可以用本地的数据库

1、安装依赖

```shell
npm i faiss-node --save
```

注意：安装这个需要环境支持 prebuild-install，最简单的是安装 Nodejs 的时候不要一直点下一步，勾选 Automatically install the necessary tools.

2、取消 src/modules/know/store/faiss.ts 文件的注释

3、取消 src/modules/know/store/index.ts 中的 // faiss: 'knowFaissStore'这个注释

4、修改`src/modules/know/config.ts`

```ts
 // 本地文件的，不需要而外安装，但是安装npm依赖需要特别注意，看下文(运行)
 store: 'faiss' as StoreTypes,
```

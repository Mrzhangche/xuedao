# Mcp服务

Mcp协议作为Function_call的延伸，更通用更强大，了解详情[https://modelcontextprotocol.io/](https://modelcontextprotocol.io/)

它可以给大模型或者一些客户端工具（如：Cursor、Cline）提供能力扩展，比如让Cursor更懂你的代码，操作你的数据库，网络搜索等等

一个不错的视频介绍Mcp：https://www.bilibili.com/video/BV12JQEYYEG6

## 使用

流程发布之后（注意一定要发布之后才是有效的，编排的时候右上角有个飞机图标），既可以直接使用

访问地址：http://127.0.0.1:8001/mcp/sse/流程的标签

注意：
- 在客户端（如：Cursor）配置的时候选择SSE类型，然后填上这个地址即可
- 流程的名称、标签（英文）、描述很重要不能随便写，它可以影响模型判断是否要调用

## 原理

- 根据流程标签找到对应的流程，检查是否是发布状态
- 找到这个流程的开始节点需要输入的参数和每个参数对应的类型和说明
- 将整个流程转换成Mcp的Tool
- 客户端通过SSE连接到服务器即可拉取可以调用的Tool，用到时自动调用

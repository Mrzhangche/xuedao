# 模型推荐

- 知识库的LLM模型推荐：[openrouter](https://openrouter.ai/)的`google/gemini-2.5-flash-preview`
理由，知识库高质量分块通常需要比较大的上下文窗口，而且也不能太笨，太贵，综合下来gemini-2.5最适合，而且输出速度很快。

- 知识库的重排模型推荐：[硅基流动](https://siliconflow.cn/zh-cn/)的`BAAI/bge-reranker-v2-m3`模型
理由，免费准确。或者用阿里云的也还可以，不会太贵。

- 知识库的向量模型推荐：[火山方舟](https://console.volcengine.com/ark/region:ark+cn-beijing/model)的`Doubao-embedding-large`，理由，向量维度高，速度快，稳定。

- 聊天模型推荐：[火山方舟](https://console.volcengine.com/ark/region:ark+cn-beijing/model)的`DeepSeek-V3`或者`
DeepSeek-R1`，理由速度快，稳定。

# 说明

有时候用户上传的文档是个扫描件，这个时候普通读取文件内容的方式是读不到的，所以需要将文档先做解析转为 Markdown 再接着处理。

# 前提条件

安装了文档转 Markdown 插件，有两个可选，开发者也可以开放其他的：

- [阿里云](https://cool-js.com/plugin/190)
- [MinerU](https://cool-js.com/plugin/191)

如果两个插件都有装则随机取一个

# 使用

如果有安装了上述插件默认就开启了高级文档解析功能，以下这些类型的文件会优先使用高级解析

- `pdf`
- `doc`
- `docx`
- `ppt`
- `pptx`
- `png`
- `jpg`
- `jpeg`

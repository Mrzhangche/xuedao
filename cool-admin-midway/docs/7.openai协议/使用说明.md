# OpenAI 兼容接口使用说明

可以通过openai协议来调用流程

## 接口地址

```
根地址: http://127.0.0.1:8001/open/flow/openai/v1
完整地址: POST http://127.0.0.1:8001/open/flow/openai/v1/chat/completions
```

## 功能说明

本接口完全兼容 OpenAI 的 Chat Completions API，可以直接使用 OpenAI SDK 或任何支持 OpenAI 协议的客户端进行调用。

## 参数映射

| OpenAI 参数 | 系统映射 | 说明 |
|------------|---------|------|
| model | label | 流程标签，用于指定要调用的流程 |
| messages | params.content | 最后一条用户消息会被提取为content参数 |
| messages | params.prompt | system类型的消息会被提取为prompt参数 |
| messages | params.messages | 历史对话消息数组（不包含最后一条用户消息和system消息） |
| stream | stream | 是否使用流式输出 |
| temperature | params.temperature | 温度参数（可选） |
| max_tokens | params.max_tokens | 最大token数（可选） |
| top_p | params.top_p | 采样参数（可选） |

## 重要：流程节点配置

### 开始节点配置
流程的**开始节点**需要配置接收以下参数：

#### 1. content（必需）
- **参数名称**：`content`
- **参数类型**：字符串
- **说明**：用户的当前问题/输入内容
- **来源**：系统会自动从 messages 数组中提取最后一条 role 为 `user` 的消息

**示例**：
```json
// 请求中的 messages
[
  {"role": "system", "content": "你是一个AI助手"},
  {"role": "user", "content": "你好"},
  {"role": "assistant", "content": "你好！有什么可以帮助你的？"},
  {"role": "user", "content": "请介绍一下自己"}
]

// content 参数将被设置为：
"请介绍一下自己"
```

#### 2. prompt（可选）
- **参数名称**：`prompt`
- **参数类型**：字符串
- **说明**：系统提示词/角色设定
- **来源**：系统会自动从 messages 数组中提取所有 role 为 `system` 的消息内容（如有多个会用换行符合并）

**示例**：
```json
// 请求中的 messages
[
  {"role": "system", "content": "你是一个专业的翻译助手"},
  {"role": "system", "content": "请使用正式的语言风格"},
  {"role": "user", "content": "翻译：Hello"}
]

// prompt 参数将被设置为：
"你是一个专业的翻译助手\n请使用正式的语言风格"
```

#### 3. messages（可选）
- **参数名称**：`messages`
- **参数类型**：JSON字符串
- **说明**：历史对话消息数组，用于多轮对话的上下文
- **来源**：系统会自动从 messages 数组中排除最后一条用户消息和所有 system 消息后，将剩余消息序列化为 JSON 字符串

**示例**：
```json
// 请求中的 messages
[
  {"role": "system", "content": "你是一个AI助手"},
  {"role": "user", "content": "你好"},
  {"role": "assistant", "content": "你好！有什么可以帮助你的？"},
  {"role": "user", "content": "我想了解AI"},
  {"role": "assistant", "content": "AI是人工智能的简称..."},
  {"role": "user", "content": "请详细说明"}
]

// messages 参数将被设置为（JSON字符串）：
'[
  {"role": "user", "content": "你好"},
  {"role": "assistant", "content": "你好！有什么可以帮助你的？"},
  {"role": "user", "content": "我想了解AI"},
  {"role": "assistant", "content": "AI是人工智能的简称..."}
]'
```

**参数配置建议**：
- **content**：必须配置，用于接收用户当前问题
- **prompt**：如果流程需要使用系统提示词，建议配置
- **messages**：如果流程需要支持多轮对话上下文，建议配置

**开始节点配置示例**：
```
开始节点参数列表：
├── content (string) - 必需，用户当前问题
├── prompt (string) - 可选，系统提示词
├── messages (string) - 可选，历史对话（JSON字符串）
├── temperature (number) - 可选，温度参数
├── max_tokens (number) - 可选，最大token数
└── ... 其他参数
```

### 结束节点配置
流程的**结束节点**必须配置输出 `content` 参数，用于返回给用户的响应内容。

- 输出参数：`content`
- 参数类型：字符串
- 说明：如果没有配置 content 输出，接口会抛出异常

**错误示例**：
```
无输出内容，注意流程结束节点需要将输出参数设置为：content
```

### 流程配置示例

**简单流程（单轮对话）**：
```
开始节点: 接收参数 content（用户当前问题）
   ↓
处理节点: 处理业务逻辑（LLM节点等）
   ↓
结束节点: 输出参数 content（AI响应）
```

**完整流程（支持多轮对话和系统提示）**：
```
开始节点: 接收参数 
   ├── content (必需) - 用户当前问题
   ├── prompt (可选) - 系统提示词
   └── messages (可选) - 历史对话
   ↓
处理节点: 使用 prompt 和 messages 构建完整上下文
   ↓
LLM节点: 调用大模型生成回复
   ↓
结束节点: 输出参数 content（AI响应）
```

## 使用示例

### 1. 使用 OpenAI Python SDK

```python
from openai import OpenAI

# 初始化客户端
client = OpenAI(
    api_key="your-api-key",  # 如果设置了IGNORE_TOKEN可以随意填写
    base_url="http://127.0.0.1:8001/open/flow/openai/v1"  # 你的API地址
)

# 非流式调用
response = client.chat.completions.create(
    model="your-flow-label",  # 替换为你的流程label
    messages=[
        {"role": "user", "content": "你好，请介绍一下自己"}
    ]
)
print(response.choices[0].message.content)

# 流式调用
stream = client.chat.completions.create(
    model="your-flow-label",
    messages=[
        {"role": "user", "content": "给我讲个故事"}
    ],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content is not None:
        print(chunk.choices[0].delta.content, end="")
```

### 4. 使用 HTTP 客户端（Axios）

```javascript
const axios = require('axios');

// 非流式调用
async function chat() {
  const response = await axios.post('http://127.0.0.1:8001/open/flow/openai/v1/chat/completions', {
    model: 'your-flow-label',
    messages: [
      { role: 'user', content: '你好' }
    ]
  });
  
  console.log(response.data.choices[0].message.content);
}

// 流式调用
async function chatStream() {
  const response = await axios.post(
    'http://127.0.0.1:8001/open/flow/openai/v1/chat/completions',
    {
      model: 'your-flow-label',
      messages: [
        { role: 'user', content: '你好' }
      ],
      stream: true
    },
    {
      responseType: 'stream'
    }
  );
  
  response.data.on('data', (chunk) => {
    const lines = chunk.toString().split('\n').filter(line => line.trim() !== '');
    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const data = line.slice(6);
        if (data === '[DONE]') {
          console.log('\n完成');
          return;
        }
        try {
          const parsed = JSON.parse(data);
          const content = parsed.choices[0]?.delta?.content;
          if (content) {
            process.stdout.write(content);
          }
        } catch (e) {
          // 忽略解析错误
        }
      }
    }
  });
}

chat();
```

## 注意事项

1. **model 参数映射**：OpenAI 的 `model` 参数会被映射为系统的 `label`，请确保传入正确的流程标签

2. **Token 验证**：默认接口已设置 `@CoolTag(TagTypes.IGNORE_TOKEN)`，忽略 Token 验证。如需要验证，请移除该注解

3. **⚠️ 流程节点配置（重要）**：
   - **开始节点**：
     - 必须配置接收 `content` 参数（接收用户当前问题）
     - 建议配置接收 `prompt` 参数（接收系统提示词，如需要）
     - 建议配置接收 `messages` 参数（接收历史对话，如需要多轮对话）
   - **结束节点**：必须配置输出 `content` 参数（返回响应内容）
   - 如果结束节点没有配置 content 输出，会抛出异常：`无输出内容，注意流程结束节点需要将输出参数设置为：content`

4. **参数传递**：
   - `content`：从 messages 数组中提取的最后一条用户消息（当前问题）
   - `prompt`：从 messages 数组中提取的所有 system 消息（系统提示词）
   - `messages`：历史对话消息数组（JSON字符串，不包含最后一条用户消息和 system 消息），可用于多轮对话上下文

5. **思考过程过滤**：流式输出中会自动过滤 `isThinking=true` 的内容，只输出最终结果

### Python 完整示例（带会话历史）

```python
from openai import OpenAI

client = OpenAI(
    api_key="any-key",
    base_url="http://127.0.0.1:8001/open/flow/openai/v1"
)

# 维护对话历史
messages = []

def chat(user_input):
    # 添加用户消息
    messages.append({"role": "user", "content": user_input})
    
    # 调用接口
    response = client.chat.completions.create(
        model="your-flow-label",  # 替换为你的流程label
        messages=messages,
        stream=True
    )
    
    # 收集助手回复
    assistant_reply = ""
    for chunk in response:
        if chunk.choices[0].delta.content:
            content = chunk.choices[0].delta.content
            print(content, end="", flush=True)
            assistant_reply += content
    print()  # 换行
    
    # 添加助手消息到历史
    messages.append({"role": "assistant", "content": assistant_reply})
    return assistant_reply

# 多轮对话示例
chat("你好，请介绍一下自己")
chat("你能做什么？")
chat("给我讲个笑话")
```

## 常见问题

### Q1: 为什么报错"无输出内容，注意流程结束节点需要将输出参数设置为：content"？

**A**: 这是因为流程的结束节点没有正确配置输出参数。请确保：
- 结束节点有输出参数
- 输出参数名称为 `content`
- content 参数包含要返回给用户的文本内容

### Q2: 如何在流程中使用消息历史？

**A**: 流程会接收三个核心参数：
- `content`: 最后一条用户消息（当前问题）
- `prompt`: 系统提示词（来自 system 消息）
- `messages`: 历史对话数组（JSON字符串，不包含最后一条用户消息和 system 消息）

**使用场景示例**：

1. **简单问答流程**：只需要 `content` 参数
   ```
   开始节点: 接收 content
   LLM节点: 使用 content 作为输入
   结束节点: 输出 content
   ```

2. **带角色设定的流程**：使用 `content` + `prompt`
   ```
   开始节点: 接收 content, prompt
   LLM节点: 使用 prompt 作为系统提示，content 作为用户问题
   结束节点: 输出 content
   ```

3. **多轮对话流程**：使用全部三个参数
   ```
   开始节点: 接收 content, prompt, messages
   处理节点: 解析 messages（JSON.parse）获取历史对话
   LLM节点: 结合 prompt、messages 历史和当前 content 生成回复
   结束节点: 输出 content
   ```

在流程中可以这样使用 messages：
```javascript
// 在代码节点中解析历史消息
const history = JSON.parse(messages); // 得到消息数组
// history 示例: [
//   {"role": "user", "content": "你好"},
//   {"role": "assistant", "content": "你好！"}
// ]
```

### Q4: prompt 参数和 content 参数有什么区别？

**A**: 
- **content**: 用户的当前问题/输入，来自 messages 中最后一条 `user` 消息
- **prompt**: 系统提示词/角色设定，来自 messages 中所有 `system` 消息

**实际例子**：
```json
// 客户端发送的请求
{
  "model": "chat-bot",
  "messages": [
    {"role": "system", "content": "你是一个专业的客服助手"},
    {"role": "user", "content": "我的订单在哪里？"}
  ]
}

// 流程开始节点会收到：
{
  "content": "我的订单在哪里？",      // 用户问题
  "prompt": "你是一个专业的客服助手", // 系统提示
  "messages": "[]"                   // 无历史消息
}
```

在流程中，通常将 `prompt` 用于设置 LLM 的角色和行为规范，将 `content` 作为实际要处理的用户输入。

### Q5: 如何切换不同的流程？

**A**: 通过修改 `model` 参数来指定不同的流程 label：

```python
# 调用客服流程
response = client.chat.completions.create(
    model="customer-service",
    messages=[...]
)

# 调用翻译流程
response = client.chat.completions.create(
    model="translator",
    messages=[...]
)
```

# 迁移变量表模板

迁移到新项目之前，先填这张表。它是后续复制、替换、检查的共同依据。

| 变量 | 示例 | 说明 |
| --- | --- | --- |
| `PROJECT_NAME` | `eotoai-care` | 项目显示名 |
| `PROJECT_CODE` | `eotoai-care` | 项目代码名 |
| `PROJECT_DESCRIPTION` | `基于 cool-admin 的 AI 项目` | 项目一句话说明 |
| `PROJECT_ROOT` | `/path/to/project` | 新项目根目录 |
| `BASE_REPO` | `/path/to/base` | base 仓库路径 |
| `BASELINE_NAME` | `cool-admin 基线` | 新项目参考的技术基线名称 |
| `DOCS_DIR` | `docs` | 新项目文档目录 |
| `SKILLS_DIR` | `skills` | 新项目 skill 目录 |
| `BACKEND_DIR` | `api` | 新项目后端目录 |
| `ADMIN_DIR` | `admin` | 新项目后台目录 |
| `MOBILE_DIR` | `uni` | 新项目移动端目录 |
| `DATABASE_TYPE` | `PostgreSQL` | 数据库类型；不确定时写“待确认” |
| `MODULE_DOC_STYLE` | `中文编号` | 模块文档命名风格 |
| `EXAMPLE_MODULE` | `知识库重建任务管理` | 新项目文档示例业务模块 |

## base 默认值

| 变量 | 默认值 |
| --- | --- |
| `BACKEND_DIR` | `cool-admin-midway` |
| `ADMIN_DIR` | `cool-admin-vue` |
| `MOBILE_DIR` | `cool-uni` |
| `DOCS_DIR` | `docs` |
| `SKILLS_DIR` | `skills` |
| `BASELINE_NAME` | `base / cool-admin 基线` |

## 填写规则

- 目录名必须写新项目真实目录，不写模板目录。
- 示例模块只用于文档示例，不代表项目默认业务。
- 数据库类型会影响是否启用 PostgreSQL 专项规范。
- 如果新项目没有某一端，写 `未启用`，不要留空。
- 如果项目已有 README 或 docs，迁移时默认保留并合并，不直接覆盖。

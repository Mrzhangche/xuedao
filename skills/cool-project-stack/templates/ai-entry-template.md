# AI 接手入口

## 先看哪里

1. `README.md`
2. `docs/README.md`
3. `AGENTS.md`
4. `skills/cool-project-stack/SKILL.md`

## 按问题路由

- 问项目全貌：看 `docs/00-system/系统总说明.md`
- 问某个模块：看 `docs/01-modules/模块名/README.md`
- 问历史决策：看对应模块版本文档和任务执行卡
- 问当前开发任务：看当前任务执行卡
- 问项目坑位：看项目专属坑位文档
- 问与 base 的差异：看 `docs/00-system/项目与base差异记录.md`

## 禁止事项

- 不要只按 base 猜当前项目。
- 不要跳过项目差异记录。
- 不要绕过 `docs/README.md` 直接扫代码。
- 不要把外部规划文件当作项目正式入口。
